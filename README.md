# SPECIMEN

A visual index of [Atlas of Type](https://type-atlas.xyz) — every typeface with a
picture of the type itself, pulled from each foundry's own page, so you can see what
is what without opening a thousand tabs.

Every card links back to the foundry it came from. The pictures are theirs; this is a
reference index, not a library. Built by [Studio BRIKD](https://github.com/rausden).
